# 🌿 GREENLOOP – Student Sustainability Registration Portal

**GREENLOOP** is a web-based student registration application designed for a Student Sustainability Fellowship. It allows students to register for environmental initiatives and contribute towards creating cleaner, greener and more sustainable campuses.

The application provides a simple registration process and generates a formatted application receipt after successful submission.

---

## ✨ Features

- Student registration form with personal and academic details.
- Multiple environmental initiative options.
- Client-side form validation using JavaScript and jQuery.
- Server-side validation using PHP.
- Live character counter for the motivation field.
- Unique registration ID generated for every successful submission.
- Formatted application receipt displayed after submission.
- Print-friendly receipt with preserved background colors.
- Responsive design for desktop and mobile devices.

---

## 🌱 Available Initiatives

Students can register their interest in:

- Tree Plantation
- Plastic-Free Campus
- E-Waste Management
- Environmental Awareness
- Waste Segregation
- Community Clean-up

## ⚙️ Installation and Setup

### Prerequisites

- PHP 8.0 or later
- Web browser (Chrome, Firefox, etc.)
- Code editor (VS Code recommended)

### Step 1: Clone the Repository

git clone https://github.com/YOUR_USERNAME/GREENLOOP.git

### Step 2: Navigate to the Project Directory

cd GREENLOOP

### Step 3: Start the PHP Development Server

php -S localhost:8000

### Step 4: Open in Browser

Visit:

http://localhost:8000/index.php

The GREENLOOP registration portal is now ready to use.

## 📝 How It Works

1. Open the GREENLOOP registration portal.
2. Enter personal and campus information.
3. Select an environmental initiative.
4. Write a short motivation describing why you want to participate.
5. Accept the information confirmation.
6. Click **Submit my application**.
7. The PHP backend validates the submitted information.
8. On successful validation, a registration ID is generated.
9. An application receipt is displayed with the submitted details.
10. Print the receipt or save it as a PDF.
